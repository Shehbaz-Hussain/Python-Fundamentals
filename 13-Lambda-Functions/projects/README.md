# Module 13 Projects — Lambda Functions

## Introduction

Welcome to the project section of **Module 13: Lambda Functions**.

The projects in this module are designed to help you apply lambda functions and Python's functional programming tools to practical programming tasks. Unlike the examples and exercises, these projects simulate realistic scenarios that involve processing, transforming, filtering, sorting, and summarizing data.

You will progressively build small applications that reinforce the concepts introduced throughout this module while developing problem-solving skills that are valuable in professional software development.

The projects focus on writing clean, readable, and maintainable Python code using:

- Lambda functions
- `map()`
- `filter()`
- `reduce()`
- `sorted()`
- The `key` parameter

Although these projects are intentionally small, they introduce patterns that are widely used in data processing, automation, reporting, analytics, and machine learning workflows.

---

# Learning Objectives

After completing all projects, you should be able to:

- Write concise lambda functions for simple operations.
- Select appropriate situations for using lambda expressions.
- Transform data using `map()`.
- Filter collections using `filter()`.
- Aggregate values using `reduce()`.
- Sort complex data structures using custom key functions.
- Process collections of tuples and lists efficiently.
- Combine multiple functional programming techniques in one program.
- Write clean, readable, and PEP 8-compliant Python code.
- Build small real-world data-processing applications.
