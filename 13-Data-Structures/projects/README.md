# Module 13 - Data Structures

# Projects

This directory contains practical projects that reinforce the concepts covered in **Module 13 – Data Structures**. These projects encourage learners to apply lists, tuples, sets, dictionaries, indexing, slicing, membership operators, unpacking, nested data structures, iteration, and built-in functions to solve real-world programming problems.

---

# Project 01 — Student Record Manager

## Purpose

Build a simple system to organize and display student records using multiple Python data structures.

## Concepts Covered

- Lists
- Dictionaries
- Tuples
- Sets
- Nested data structures
- Iteration
- Membership operators
- Built-in functions (`len()`, `sum()`)
- Basic calculations

## Skills Developed

- Organizing structured data
- Choosing appropriate data structures
- Accessing nested data
- Processing collections using loops
- Writing clean and readable Python code

---

# Project 02 — Inventory Management System

## Purpose

Develop a basic inventory management program that stores, processes, and displays product information using Python data structures.

## Concepts Covered

- Lists
- Dictionaries
- Tuples
- Sets
- Tuple unpacking
- Nested data structures
- Membership operators
- Iteration
- Built-in functions (`len()`, `sum()`)

## Skills Developed

- Managing structured business data
- Combining multiple data structures
- Calculating inventory values
- Displaying formatted information
- Solving practical programming problems

# Suggested Extensions

After completing both projects, consider adding the following features:

- Accept user input instead of hard-coded data.
- Search for records by name or ID.
- Update existing records.
- Delete records safely.
- Sort records alphabetically or numerically.
- Display summary statistics.
- Validate user input.
- Save and load data using file handling (after studying the corresponding module).
- Create a menu-driven application using functions (after completing the Functions module).
- Implement object-oriented versions of the projects (after learning OOP).

# Learning Outcomes

After completing these projects, you should be able to:

- Select the appropriate data structure for a given problem.
- Work confidently with lists, tuples, sets, and dictionaries.
- Access data using indexing and slicing.
- Use membership operators effectively.
- Iterate through different data structures.
- Work with nested data structures.
- Apply commonly used built-in functions.
- Write clean, organized, and maintainable Python programs.
- Build a solid foundation for future topics such as file handling, object-oriented programming, data analysis, and artificial intelligence.
