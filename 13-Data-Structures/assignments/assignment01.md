# Module 13 - Data Structures

# Assignment 01 — Student Information Manager

## Difficulty

Easy

---

# Objective

Create a Python program that stores and displays student information using Python data structures. The assignment is designed to reinforce the concepts of lists, tuples, sets, dictionaries, indexing, slicing, membership operators, and iteration.

---

# Learning Outcomes

After completing this assignment, you should be able to:

- Create and use lists, tuples, sets, and dictionaries.
- Access elements using indexing and slicing.
- Check membership using `in` and `not in`.
- Iterate through different data structures using `for` loops.
- Apply appropriate built-in functions such as `len()`, `min()`, `max()`, and `sorted()` where applicable.

---

# Requirements

Write a Python program that:

1. Creates a list containing at least five student names.
2. Creates a tuple containing five student ID numbers.
3. Creates a set containing the names of subjects offered.
4. Creates a dictionary where:
   - The key is the student name.
   - The value is the student's age.
5. Displays:
   - The complete list of students.
   - The first and last student using indexing.
   - A slice containing the middle three students.
   - The tuple of student IDs.
   - The set of subjects.
   - The dictionary of student ages.
6. Checks whether a student named **"Ali"** exists in the list.
7. Iterates through:
   - The list
   - The tuple
   - The set
   - The dictionary
